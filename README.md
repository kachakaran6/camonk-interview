# CA Monk – Blog Application

A modern blog application built using React, TypeScript, TanStack Query, Tailwind CSS, and shadcn/ui.

## Features

- Blog list & blog detail view
- Create new blog
- Server state management with TanStack Query
- Independent scroll panels
- Dark mode support
- Mobile-friendly navigation
- Clean & responsive UI

## Tech Stack

- React + TypeScript
- TanStack Query
- Tailwind CSS
- shadcn/ui
- JSON Server

## Setup Instructions

### Backend

```bash
npm install
npm run server
```
